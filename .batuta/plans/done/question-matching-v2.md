**Task 1.** The full passage is what `questions.Passage` returns (`questions/passage.go` ~24): the title line, `Scope: ` lines, `Accept: ` lines, a blank line, then the context paragraphs. A unit keeps its `Scope: ` or `Accept: ` prefix. The UTF-8 bound to copy is the one `Passage` uses (~42–55). A sentence end is a period, exclamation or question mark followed by whitespace; a period inside a path or identifier such as `loop/panel.go` is not followed by whitespace and does not split.

**Task 2.** The bench is `runQuestionsBench` and `questionsBenchRecordFor` (`cmd/batuta/judge_questions_bench.go` ~71 and ~177); the label type with its `note` is `questionsLabel`; the summary is `questionsBenchSummary` and `questionsBenchCountRecords` (~216). Curly double quotes are U+201C and U+201D. P(`answered_here`) is `Probabilities["answered_here"]` of the answer; when it is absent the unit scores zero. Keep the state shape `{question, passage}` on every request. The bench tests use a local HTTP test server that answers per request body.
