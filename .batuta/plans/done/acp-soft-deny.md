# Plan — a denied ACP permission request no longer ends the session, and every denial is recorded
<!-- inputs: profile.md@sha256:e18a00765937 routing.md@sha256:bdb31fda5c7d -->

**Goal:** Under the worktree policy (core#125), a denied permission request fails the whole ACP session with `permission_denied` and an uncertain submission. That kills ordinary work: in a Batuta worktree the gitdir lives in the main repository, outside the worktree, so a codex `git add`/`git commit` becomes an `execute` escalation request, the policy rejects it, and delivery `decoder-errors-20260925-101331` aborted after 2 minutes (reproduced by `.batuta/acp-probes/qualify-2026-09-23/mode_probe.py` case `gitadd` with `WORKTREE=1`). On the CLI path the same command just fails and the agent carries on. The session must answer a denial with the reject option the agent offered and continue, and the receipt must record every denied request, since today nothing says what was denied.

## Decisions and context

Go standard library only, conventional commits. The policy's decision itself does not change: nothing outside the worktree is approved, and `execute` requests without locations are still denied (approving a codex escalation would run the command outside its sandbox with full access). Only the consequence of a denial changes, so that it matches the CLI path.

**Task 1.** The terminal path is in `executor/acp/permission.go` (~66–74): `selected == ""` answers `cancelled` and calls `s.conn.fail(ErrPermissionDenied)`. Keep validation exactly as is; after the policy runs, if nothing was selected, look for an offered option with kind `reject_once` and answer with it instead of failing, recording the denial on the session. Command comes from `toolCall.rawInput.command` when it is a string; Title from `toolCall.title` (add the field to PermissionRequest.ToolCall). `TurnResult` is in `executor/acp/session.go` (~46); the receipt is `executor/receipt.go` (~65); `ACPBackend.Execute` copies turn data into the receipt in `executor/acp_backend.go`. `acp_native_test.go` (~114) sends a request with only an `allow_once` option, so it keeps the terminal assertion. The real-provider requalification of the permission case is done by the conductor after this plan, not here.
