# Plan — judge package: Jev decisions with a fail-closed fallback
<!-- inputs: profile.md@sha256:e18a00765937 routing.md@sha256:1615c7990def -->

**Goal:** Give the core a `judge` package that asks a System One decision model (TypeSafe Jev, directly or through OpenRouter) typed `noul`/`choice`/`score` questions over a bounded state, configured from `.batuta/judge.json` and the `BATUTA_JUDGE` environment variable, with every failure surfacing as a typed `ErrUnavailable` so callers keep today's deterministic rule. Ships with a `batuta judge` CLI for manual probes and a trace record shape for later journaling. No decision point in the loop changes in this plan; that is the next plan (`.batuta/judge-research.md`, section 5).

## Decisions and context

Go standard library only (`net/http`, `net/http/httptest`, `encoding/json`, `crypto/sha256`), frozen exported signatures outside the new `judge` package, conventional commits, no journal schema change in this plan. Tests never touch the network: every HTTP test runs against `httptest.NewServer`. Secrets never land in a file, a journal record, a log or a test fixture. Read `.batuta/judge-research.md` sections 1, 2 and 5 before starting: they hold the API shapes, limits and the safety rules.

Native request shape, from the TypeSafe API reference: `POST {base_url}/v1/systemone` with header `Authorization: Bearer <key>` and body `{"state": <string|object|array>, "model": "<model>", "questions": {"<key>": {"type": "noul"|"choice"|"score", "instructions": <string|object>, "criteria": <map for choice | array for score | optional {"true":..,"false":..} for noul>}}}`. Response `{"model": "jev-1.13.0", "answers": {"<key>": {"type": "noul", "noul": 0.93} | {"type": "choice", "choice": "k", "confidence": 0.78, "probabilities": {...}} | {"type": "score", "score": 1.0, "confidence": 1.0, "probabilities": {...}}}, "usage": {"input_tokens": n, "output_tokens": n}}`. Limits: 64k tokens per request, 32k for the state; 255 options per choice; 429 on rate limit. OpenRouter: `POST https://openrouter.ai/api/alpha/decisions`, model `typesafe/jev-1.13`, same body, errors as `{"error": {"code": ..., "message": ...}}`. Vercel AI Gateway exposes Jev only through the AI SDK today; its raw HTTP contract is not documented, so the provider exists in the enum and refuses with `transport_undocumented`.

**Task 1.** Package `judge`. Exported surface: `type Judge interface { Ask(ctx context.Context, req Request) (Response, error) }`; `Request{Decision string; State any; Questions map[string]Question}`; `Question{Type QuestionType; Instructions any; Criteria any}`; `Response{Model string; Answers map[string]Answer; Usage Usage}`; `Answer{Type QuestionType; Noul float64; Choice string; Score float64; Confidence float64; Probabilities map[string]float64}`; `ErrUnavailable` as a sentinel wrapped by `UnavailableError{Reason string; Err error}` with reasons among `judge_off`, `key_missing`, `transport_undocumented`, `timeout`, `rate_limited`, `server_error`, `malformed_response`, `answer_mismatch`, `state_too_large`; `Provider` string enum `typesafe`, `openrouter`, `vercel`; `NewHTTPJudge(Options{Provider, BaseURL, Model, Key, Timeout, MaxStateBytes, Client *http.Client})`. Default base URLs: `https://api.typesafe.ai` and `https://openrouter.ai/api/alpha` with the path chosen per provider (`/v1/systemone` versus `/decisions`); an explicit `BaseURL` overrides for tests. Serialize the state once with `encoding/json` to measure it against `MaxStateBytes` before sending. Validate answers: every question key answered, types match, choice option is one of the criteria keys. Do not retry inside the client; the caller decides.

**Task 2.** `LoadConfig(root string, getenv func(string) string) (Config, error)`. File `.batuta/judge.json`: `{"provider": "typesafe", "model": "jev-latest", "base_url": "", "key_env": "TYPESAFE_API_KEY", "timeout_ms": 3000, "max_state_bytes": 100000, "decisions": {"<name>": {"mode": "shadow", "threshold": 0.9}}}`. Follow `LoadSupervisionPolicy` in `loop/supervision_notify.go` for the reading discipline (size cap, `DisallowUnknownFields`, exactly one object). `BATUTA_JUDGE` is `off`, empty (use the file) or an absolute or root-relative path to another JSON file. `key_env` must match `^[A-Z][A-Z0-9_]*$`; the default per provider is `TYPESAFE_API_KEY` or `OPENROUTER_API_KEY`. `Config.Judge(getenv) (Judge, error)` builds the HTTP judge or returns `ErrUnavailable` with `judge_off` or `key_missing`. `Config.Decision(name) DecisionConfig` returns `{Mode: "off", Threshold: 0}` for unknown names so an unconfigured decision is off.

**Task 3.** `Traced{Judge Judge; Sink func(kind string, record any) error; Clock func() time.Time}` with record kinds as string constants `judge_intent` and `judge_result` (not journal kinds yet: the loop adopts them in the next plan). `StateDigest(state any) (string, error)` canonicalizes by marshalling to JSON with sorted keys (marshal, unmarshal into `any`, marshal again) and returns `sha256:<hex>`. Records are plain structs with `json` tags so a future journal detail can embed them unchanged.

**Task 4.** Subcommand `judge` in `cmd/batuta/main.go`'s switch and in the `commands` slice (keep the slice sorted as it is), implemented in `cmd/batuta/judge.go` with `flag.NewFlagSet` like the other subcommands. `ask` flags: `--state-file`, `--questions-file` (a JSON object in the request `questions` shape), `--decision` (name for the trace, default `manual`), `--config` (path, default `.batuta/judge.json` under `--workspace` or the current directory), `--base-url` (test override). Output: the `Response` as indented JSON. `probe` sends `{"ok": {"type": "noul", "instructions": "The state says the connection works."}}` over the state `"connection check"`. Exit codes: 0 answered, 2 unavailable, 1 usage or config error, matching the review command's convention of a distinct non-zero for a non-failure outcome. Tests follow `cmd/batuta/main_test.go` patterns and use an httptest server. `docs/judge.md` mirrors the tone of `docs/review.md`: what the judge is, the config file, the environment variables, the providers table, the CLI, and the safety rules from the research note (the judge never approves, clears a gate, answers a question or widens a scope; shadow mode first).
