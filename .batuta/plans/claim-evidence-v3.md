## Decisions and context

Go standard library only, frozen exported signatures except the additions named in the tasks, conventional commits, no real judge calls in tests (use the existing fake judge). The judge may only make a verdict stricter; unavailability changes nothing. Read `.batuta/judge-benchmark.md` "Reanalysis of constructed-corpus run 1" first: the judge's contradicted probability separated `behaviour_absent` from `clean` with AUC 0.968, and the batuta's double gate (choice confidence ≥ threshold and material ≥ threshold) discarded it.

Worktree executors cannot read `.batuta/journal/`: tests use fixture journals, run logs and corpus files written in the test. Building the corpus, calibrating, freezing the threshold and running the test half are conductor steps after task 3.

**Task 1.** Move the aggregation into one exported function in `loop/judgment.go` and delete the copies (`aggregateClaimEvidence` in `loop/judgment.go`, `aggregateReplayClaims` in `cmd/batuta/judge.go`); `claimEvidenceFlagDetail` and `enforceClaimEvidence` use the same rule. The contradicted probability is the existing `contradictedProbability` (sum over defect options). `material` stays asked and recorded (`material_max`) but never gates. Keep the uncertain band lower bound `uncertainContradictedLow` (0.30); its upper bound becomes the threshold. The `unverifiable` criterion keeps "says nothing decisive about the claim" and drops the sentence about short slices. Update the replay and corpus tests whose expected `flagged` or uncertain counts change, and say which in the commit body.

**Task 2.** The two new labels are built exactly like `behaviour_absent` in `cmd/batuta/judge_corpus.go`, reusing its "next source case from a different delivery" pairing. `true_behaviour` is a negative (should not flag); `wrong_diff` is a positive. Keep ids `<delivery>/<task>/e<execution>/<label>` and output sorted by id.

**Task 3.** `calibrate` is a form of `corpus` (`batuta judge corpus calibrate`). It asks the judge once per calibrate case with unsettled claims and derives every threshold's counts from the recorded contradicted probabilities, so the sweep costs one call per case. Positives: `behaviour_absent`, `wrong_diff`, `fabricated_reference`, `wrong_count`. Negatives: `clean`, `true_behaviour`. Code flags count at every threshold.
