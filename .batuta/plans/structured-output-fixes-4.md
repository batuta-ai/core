## Decisions and context

Go standard library only, conventional commits. Nothing here changes routing, gates or outcomes. Task 2 edits only a comment in `executor/acp_native.go`, no code.

**Task 1.** Today `decodeWriter.Write` (run.go ~300) appends the payload and cuts `pending` to `outputLimit` before searching for `\n`, so a large chunk loses complete lines and, once an unterminated prefix fills the cap, every later event is cut away. Required order: append, emit every complete line, then if the leftover partial line exceeds `outputLimit`, drop it, set `truncated` and enter a skip state that discards bytes until the next `\n`; the event after that newline decodes normally. `flush()` must not emit a line that was dropped. Rewrite `TestDecodeWriterBoundsPendingLine` (run_test.go ~291) to write a follow-on complete `cursor-stream-json` assistant event after the overlong line and assert its text reaches the destination; build that event like the fixtures under `executor/testdata/stream/`. In `TestUsageTotalBySemantics` (usage_test.go ~59) the current `cost := 0.75` truncates to 0 and the subset/unset fixtures leave `CacheReadTokens`/`CacheWriteTokens` nil, so neither would catch a wrong sum.

**Task 2.** Facts: `NewNativeTransport` (acp_native.go ~14) sets qualification `Model: "*"` and `Effort: ""`; `ACPQualification.matches` (transport.go ~97–104) accepts any requested model for `*` and any requested effort when both the qualification's `Effort` and `Adapter.ACP.EffortConfigID` are empty, without reading session options; `acp.NewSession` then checks the model is advertised and confirmed and may skip the effort, which `ACPBackend` records as `not_applicable` (acp_backend.go ~91). In `executor/run.go`, `Adapter.Outcome` runs `usage_regex` on the decoded text first, and `Result.Usage` is overwritten with provenance `cli/<decoder>` only when the decoder reports usage. Fix docs/dispatch.md ~57 (factory sentence) and ~168 (the sentence after "only when the session skipped"), and docs/loop.md ~218 (the `Result.Usage` sentence). Keep the release facts (OpenCode 1.18.31, `opencode acp`, darwin/arm64).
