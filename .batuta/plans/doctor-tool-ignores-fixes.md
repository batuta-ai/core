## Decisions and context

Source: the review report `.batuta/reviews/supervision/3210e9c9a9a2ba12c87853575c1b9d9db813f3611506647fb67ae95806730201/artifacts/review.md`. The conductor accepted all 14 findings. The approved behaviour of the original plan (`.batuta/plans/done/doctor-tool-ignores.md`) stays: its decision table, statuses, hints and API do not change except where a task below says so. Keep every existing test passing and add the new ones next to the tests of the same file.

Segment matching: `hasBatutaSegment(s)` removes every backslash, splits on `/`, and holds when one segment equals `.batuta`. Every place that today tests a keyed literal, a Jest pattern or an ignore entry with a substring check for `.batuta` uses it instead. A keyed literal is still found with `keyLiterals`; only the test on its text changes.

**Task 1.** `check` uses `os.Lstat` on `root/.batuta`: absent is the no-findings case, a symlink is followed with `os.Stat` and must reach a directory, anything else is the existing error. At EOF `stripComments` reports an unterminated template when any open template substitution remains on its stack, not only when the top entry is one. Escape decoding handles `\xHH`, `\uHHHH` and `\u{H...}`, and keeps the existing single-character escapes. In `keyLiterals`, a computed member `[...]` followed by `:` or `(` is a sibling key named `[computed]`. In `callLiterals`, a name preceded by the keyword `function`, or whose closing `)` is followed by `{`, is not a call.

**Task 2.** Inside a quoted word, a backslash escapes the next character, the shell's rule for double quotes; single quotes keep the existing behaviour. The Playwright `testDir` value is cleaned with `path.Clean` after converting it to slashes; an absolute value or one whose cleaned form starts with `..` keeps taking the no-`testDir` rows, and the first segment of the cleaned value decides the `.batuta` row.

**Task 3.** Biome v2: a pattern, after dropping a leading `!!` or `!` and a leading `./`, matches `.batuta` when it is `**` or `**/*`, or when its first segment is `.batuta`, or when it starts with `**/.batuta` followed by the end or by `/`. Biome v1: a `files.ignore` entry ignores the root `.batuta` when, after dropping a leading `./`, a trailing `/`, `/**` or `/**/*`, it equals `.batuta` or `**/.batuta`. pytest: the `testpaths` shortcut gives `not_needed` only when every entry is a named directory whose cleaned first segment is not `.batuta` and at least one entry exists as a directory under the root, because pytest falls back to the root when no `testpaths` entry matches; otherwise the row is `missing` with the existing hint.

**Task 4.** In `docs/doctor.md` replace the sentence that applies script discovery to every tool with one that lists the tools found from `package.json` scripts (vitest, jest, playwright, eslint, prettier, biome) and adds that TypeScript and pytest are found only from their root configs. In the done plan, change only the Biome version paragraph, to say a pattern matches `.batuta` as a whole segment, and the Biome v1 `ignored` row, to the root rule of task 3; leave every other line as it is.
